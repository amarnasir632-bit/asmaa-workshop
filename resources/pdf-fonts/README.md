# ملفات خطوط PDF

تستخدم واجهات التطبيق خط Tajawal المحلي المقدم من مالك المشروع (الملفات الأصلية في `font/Tajawal/`). يظل PDF عبر `tc-lib-pdf` على DejaVu Sans المرفق هنا.

تم اختبار تضمين Tajawal المحوّل مع `tc-lib-pdf` محلياً، لكن المعاينة المرئية أظهرت محارف مفقودة؛ لذلك لا يستخدمه مولد PDF حالياً ولا تعدّ العربية في PDF مطابقة للهوية. أصول Tajawal المحوّلة محفوظة مؤقتاً في مجلد `tajawal/` للرجوع إليها، ولا يعتمدها التطبيق.

لا يوجد ملف ترخيص ضمن ملفات Tajawal المقدمة. مصدر الخط وترخيص إعادة توزيعه يحتاجان إلى توثيق المالك قبل إعادة توزيع الخط خارج نطاق المشروع. DejaVu Sans المرفق مع ملف الترخيص يستخدم لتوليد PDF حتى ينجح اختبار مرئي صحيح باستخدام Tajawal.
