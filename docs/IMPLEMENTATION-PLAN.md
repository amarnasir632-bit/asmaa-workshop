# خطة التنفيذ

الخطة تنفيذ مرحلي؛ SRS معتمدة حسب تحديث المالك. لا نشر عام أو تشغيل على قاعدة بيانات حقيقية دون إذن منفصل، ويظل اختيار المضيف مشروطاً بالتحقق.

## الدفعة 1: فحص المتطلبات والتحقق التقني — أُنجزت وثائقياً

فحص المشروع وGit والهوية وقراءة SRS كاملة، وإعداد المراجعة والخطة والقرارات والتوافق ومصفوفة التتبع. لم ينشأ تطبيق أو مخطط قاعدة بيانات نهائي ولم تنفذ ترحيلات.

## بوابة اعتماد قبل الدفعة 2 — اجتازها المالك

وافق مالك النظام وحدث حالة SRS إلى «معتمدة» بتاريخ 14 أكتوبر 2026. ملفات الهوية أُرفقت كمرجع. تبقى تفاصيل الحسابات والسياسات التقنية مسجلة في التصميم قبل الوحدات التي تعتمد عليها.

## الدفعة 2: التصميم المعماري والبيانات والصلاحيات — اكتمل مبدئياً

- رسم الكيانات والعلاقات التي في SRS وتوثيق أي تطبيع/دمج.
- توثيق تدفقات المالية والمخزون والمعاملات، الحالات المنفصلة، الأرشفة والتصحيح.
- إعداد مصفوفة صلاحيات خادمية، وتصميم حماية المرفقات وسجل التدقيق والنسخ والتصدير والاستعادة.
- أُعدت الوثائق والمخططات والمigrations. تُستخدم قاعدة SQLite داخل الذاكرة للاختبارات؛ لا قاعدة تشغيلية حتى اختيار مضيف ومحرك إنتاج.

## الدفعة 3: تأسيس المشروع والقاعدة والمصادقة — منفذة جزئياً

تم تأسيس Laravel 13 وملفات الإعداد والمصادقة والصلاحيات وإدارة المستخدمين وسجل التدقيق. migrations تُختبر على SQLite؛ لم تُنشأ قاعدة تشغيل. المتبقي اختبار MySQL نظيف ونشر على مضيف حقيقي.

## الدفعة 4: العملاء والمقاسات والمدارس والأصناف والطلبات — منفذة جزئياً

أولياء الأمور والأطفال والمقاسات ولقطتها؛ المدارس والمراحل والأصناف الأساسية والطلبات الفردية والعقود المدرسية موجودة بواجهة وخادم وصلاحيات وتدقيق واختبارات، مع نواقص تعديل الطلبات وتغطية الاختبارات التي سجلتها مصفوفة المتطلبات.

## الدفعة 5: الإنتاج والترزي والتسليم والمخزون — منفذة جزئياً

الإنتاج والإرسال والاستلام الجزئي والكلي؛ مخزون جاهز وجرد وحركات وتصحيحات؛ التسليم الجزئي والكلي. معاملات وقيود/أقفال مناسبة لمنع السباقات والمخزون السالب. يلزم تحقق إضافي على MySQL واختبار التزامن على محرك الإنتاج.

## الدفعة 6: المالية — منفذة جزئياً

دفعات نقدية وتحويلات معلقة واعتماد المدير وأدلة خاصة؛ مصروفات وحساب موحد للاستحقاق والتحصيل والربح التقديري؛ إلغاء وخصم أولي واسترداد مستقل وتدقيق؛ تقارير واختبارات للحالات الحدية.

## الدفعة 7: اللوحة والتقارير والاستعلام والتدقيق والنسخ — منفذة جزئياً

لوحة وإشعارات وتقارير وطباعة/PDF؛ استعلام محدود وتحديد المعدل؛ تدقيق محمي وترحيل التاريخ؛ نسخ/استعادة حسب الاستضافة. واجهة الأرشفة تحفظ مصدر السجل والتصحيحات للمدير ولا تكتب إلى الدفاتر التشغيلية. لا توجد عملية اعتماد نهائي/مصالحة أو رفع مجموعة ملفات؛ لا ادعاء بتحقق أهداف النسخ دون استعادة ناجحة موثقة.

## الدفعة 8: الاختبارات والتهيئة والنشر التجريبي — غير مكتملة

اختبارات قبول وظيفية وأمنية ومالية ومخزنية؛ أداء موثق (50 متزامناً و95% خلال ثانيتين)؛ تثبيت ونشر واستعادة على بيئة هدف ببيانات اصطناعية. توثيق Fedora والنشر والاستعادة والقيود. لا نشر عام أو بيانات حقيقية دون إذن صريح.

## بوابة كل دفعة

شغّل الاختبارات ذات الصلة، أصلح العيوب، حدّث حالة المصفوفة مع دليل الاختبار، وسجل الملفات المتغيرة قبل الانتقال. لا يكتمل مطلب بمجرد الواجهة أو نجاح البناء. لا عمليات مدمرة أو نشر أو رفع بيانات حقيقية ضمن هذه الخطة دون الإذن المحدد.
