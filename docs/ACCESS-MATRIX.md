# مصفوفة الصلاحيات المقترحة

هذه ترجمة تنفيذية أولية لـSRS وليست توسيعاً للصلاحيات. كل تفويض يتحقق في الخادم. لا يعني منع العملية من الواجهة منع تجاوزها؛ يجب اختبار الطلب المباشر أيضاً.

| العملية | المدير | الموظف |
|---|---:|---:|
| إدارة/تعطيل المستخدمين والأدوار والصلاحيات | نعم | لا |
| قراءة/إنشاء/تعديل أولياء الأمور والأطفال والمقاسات | نعم | نعم، مع الأرشفة بدل الحذف |
| قراءة المقاسات والتاريخ | نعم | نعم حسب الحاجة التشغيلية |
| المدارس والمراحل والأصناف والأسعار | نعم | قراءة؛ تعديل بحسب permission تشغيلية تمنح مركزياً |
| إنشاء الطلب وتعديل غير المالي قبل اعتماد عمليات مالية/تسليم | نعم | نعم |
| إنشاء/تعديل المستفيدين وبنود العقد | نعم | نعم |
| تسجيل مراحل الإنتاج وإرسال/استلام الترزي | نعم | نعم |
| إنشاء التسليم بعد تحقق الخادم من شروطه | نعم | نعم |
| تسجيل حركة بيع مخزون جاهز بعد تحقق الرصيد | نعم | نعم |
| اعتماد أرصدة افتتاحية وفروقات جرد | نعم فقط | إعداد/إدخال مسودة إن فُوض؛ لا اعتماد |
| تسجيل دفعة نقدية أو تحويل بانتظار التحقق | نعم | نعم وفق SRS |
| تأكيد تحويل بنكي | نعم فقط | لا |
| قراءة/تنزيل إشعار تحويل | نعم | موظف مفوض للطلب فقط وبالتدقيق؛ لا رابط عام |
| تسجيل مصروف | نعم | وفق الصلاحية الممنوحة |
| اعتماد إلغاء/قرار خصم أولي | نعم فقط | لا؛ يرفع طلب إلغاء إن أضيف كتدفق |
| اعتماد/تنفيذ استرداد | نعم فقط | لا |
| تصحيح مالي حساس | نعم فقط | لا |
| قراءة التقارير التشغيلية | نعم | المسموح فقط |
| قراءة التقارير المالية | نعم | لا افتراضياً؛ تُمنح صراحة إن اعتمد المالك |
| قراءة سجل التدقيق | نعم | لا |
| تصحيح بيانات تاريخية حساسة | نعم فقط مع سبب | لا |
| تصدير/استعادة نسخة احتياطية | مدير مخول/مسؤول تشغيل منفصل | لا |

## سياسة التنفيذ

- الرفض الافتراضي؛ لا توجد صلاحية لمجرد اختفاء زر.
- فحص المستخدم الفعال والدور والصلاحية ونطاق السجل (مثل الطلب المرتبط) على كل endpoint.
- العمليات المالية/المخزنية والتسليم تفحص السياسة وتكتب التغيير والتدقيق داخل معاملة واحدة متى أمكن.
- لا يمنح دور «مدير» بمجرد تسجيل عام؛ حساب المدير الأولي ينشأ في تثبيت محلي/إجرائي سري ثم يطلب كلمة مرور جديدة.
- سجل التدقيق لا يعد بديلاً عن القيود البنيوية للدفعات والحركات غير القابلة للحذف.

## ما يحتاج اعتماداً قبل تثبيت Permissions

- أي صلاحيات تشغيلية للموظف لإدارة المدارس/الأصناف أو قراءة التقارير المالية.
- نطاق قراءة المرفقات المالية للموظف حسب المهمة.
- هل يسمح الموظف بإدخال مسودة إلغاء/استرداد دون اعتماد نهائي.

العمليات الحساسة المحجوزة للمدير في SRS لا تتغير بهذه المصفوفة.
