# قائمة تحقق النشر على InfinityFree

استخدم هذه القائمة قبل النشر وبعده. **لا تُعلن النشر ناجحاً حتى تُنفَّذ الفحوص الفعلية
على الخادم** (لا يكفي نجاح البناء المحلي).

## قبل البناء (على جهاز المطوّر)

- [ ] `composer validate --no-check-publish` ناجح.
- [ ] `php artisan test` ناجح (SQLite).
- [ ] `vendor/bin/pint --test` ناجح.
- [ ] `npm run build` ناجح.
- [ ] لا تعديلات معلّقة تغيّر قواعد العمل.
- [ ] `build/infinityfree-htdocs.zip` مبني من أحدث كود.

## قبل الرفع

- [ ] حُذفت ملفات `htdocs` الافتراضية للمنصة.
- [ ] قاعدة البيانات أُنشئت وبيانات `DB_*` محفوظة.
- [ ] استُورد `sql/01-schema.sql` بلا أخطاء.
- [ ] استُورد `sql/02-seed.sql` بلا أخطاء.
- [ ] طُبّق SQL المدير الأول من `tools/generate-manager-sql.php`.
- [ ] الحزمة لا تحتوي `.env` أو `vendor` تطويرية أو `node_modules` أو سجلات أو SQLite.
- [ ] `APP_KEY` و`APP_BACKUP_KEY` أُنشئا وحُفظا خارج المستودع.

## بعد الرفع

- [ ] الملفات: `htdocs/index.php`, `htdocs/.htaccess`, `htdocs/asmaa/`, `htdocs/build/`.
- [ ] أُنشئ `htdocs/asmaa/.env` بالقيم الإنتاجية (`APP_ENV=production`, `APP_DEBUG=false`).
- [ ] `storage/` و`bootstrap/cache/` قابلة للكتابة.
- [ ] فُعّلت شهادة SSL و`APP_URL` يبدأ بـ`https`.

## فحوص الأمان (أهم خطوة — نفّذها من المتصفح)

افتح كل رابط وتأكد أن النتيجة **403 أو 404 فقط**، وليس محتوى الملف:

- [ ] `https://<نطاقك>/asmaa/.env`
- [ ] `https://<نطاقك>/asmaa/composer.json`
- [ ] `https://<نطاقك>/asmaa/vendor/autoload.php`
- [ ] `https://<نطاقك>/asmaa/storage/logs/laravel.log`
- [ ] `https://<نطاقك>/asmaa/database/`
- [ ] `https://<نطاقك>/.env`
- [ ] `https://<نطاقك>/.git/config`

> إذا ظهر أي محتوى من هذه الملفات، **أوقف التجربة فوراً** وأبلغ: العزل غير محقق.

## فحوص وظيفية (بيانات اصطناعية)

- [ ] `/login` يفتح ويظهر التصميم والخط والاتجاه RTL.
- [ ] الدخول بحساب المدير يعمل، والخروج يعمل.
- [ ] `active.staff`: تعطيل مستخدم يمنع وصوله.
- [ ] ولي أمر + طفل + مقاسات: إنشاء وعرض.
- [ ] طلب فردي متعدد البنود + طلب جاهز (يلزم توفر مخزون).
- [ ] دورة الإنتاج: مهمة → إرسال للترزي → استلام جزئي.
- [ ] تسليم مع منع التسليم قبل السداد.
- [ ] دفعة نقدية وتحويل بنكي (يتطلب اعتماد المدير).
- [ ] رفع مرفق دليل تحويل، ثم تنزيله كمستخدم مخوّل.
- [ ] إلغاء + استرداد + تصحيح مالي (المدير).
- [ ] الرصيد الافتتاحي وتسوية الجرد تتطلبان اعتماداً.
- [ ] المخزون: منع البيع عند عدم الكفاية.
- [ ] التقارير التشغيلية والمالية تعمل، وعزل بيانات الموظف.
- [ ] تصدير PDF عربي ثم فحصه بصرياً (اتجاه ومحارف).
- [ ] واجهة الاستعلام العامة بالاسم/التواصل.
- [ ] سجل التدقيق للقراءة فقط للمدير.
- [ ] الإشعارات الداخلية عند فتح اللوحة.

## الجاهزية التشغيلية للنسخ

- [ ] تصدير قاعدة بيانات يدوي ناجح ووُضع خارج الاستضافة.
- [ ] تنزيل مجلد المرفقات الخاصة ناجح.
- [ ] استعادة تجربة على بيئة/قاعدة اختبار ناجحة.
- [ ] لا نسخ داخل `htdocs`.
- [ ] إدراك أن النسخ التلقائي غير متاح (لا Cron) → RPO/RTO غير محققين.
